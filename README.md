# גליל חדש

## מקור הסמכות היחיד

כל הדרישות המחייבות של הפרויקט נמצאות **רק** בקובץ [`SOURCE_OF_TRUTH.md`](SOURCE_OF_TRUTH.md).

הקובץ הזה (`README.md`) הוא דף ניווט בלבד. הוא אינו מגדיר דרישות, אינו מפרש דרישות ואינו רשאי להחליף או להשלים את מקור האמת.

כל קובץ אחר בריפו — קוד, דפי HTML, QA, פרובננס, מקורות, מעקב או תיעוד — חייב להיגזר מ־`SOURCE_OF_TRUTH.md` ואינו מקור סמכות עצמאי.

## ניווט

- [`SOURCE_OF_TRUTH.md`](SOURCE_OF_TRUTH.md) — מקור הדרישות היחיד.
- [`SOURCES.md`](SOURCES.md) — מפת מקורות/ראיות בלבד.
- [`PROVENANCE.md`](PROVENANCE.md) — תיעוד היסטורי של מקורות הקוד בלבד.
- [`CLAUDE.md`](CLAUDE.md) — הוראות תפעול ל־Claude Code בלבד.

## מצב האפיון

האפיון של "גליל חדש" עדיין פתוח. אין להסיק שהמפרט הושלם עד שיניב מודיע זאת במפורש.

## בדיקת מניעת פיצול מקור אמת

```bash
node ssot-qa.mjs
```

בדיקה זו חייבת להישאר ירוקה ומטרתה למנוע יצירת מקור אמת מתחרה.

## QA קיים

```bash
node qa.mjs
```

לפני שינוי בדרישות: מעדכנים קודם את `SOURCE_OF_TRUTH.md`, ורק לאחר מכן את המימוש והבדיקות.
