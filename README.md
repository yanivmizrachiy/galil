# גליל חדש

## מקור הסמכות היחיד

כל הדרישות המחייבות של הפרויקט נמצאות **רק** בקובץ [`SOURCE_OF_TRUTH.md`](SOURCE_OF_TRUTH.md).

הקובץ הזה (`README.md`) הוא דף ניווט בלבד. הוא אינו מגדיר דרישות, אינו מפרש דרישות ואינו רשאי להחליף או להשלים את מקור האמת.

כל קובץ אחר בריפו — קוד, דפי HTML, QA, פרובננס, מעקב או תיעוד — חייב להיגזר מ־`SOURCE_OF_TRUTH.md` ואינו מקור סמכות עצמאי.

## בדיקת מניעת פיצול מקור אמת

```bash
node ssot-qa.mjs
```

בדיקה זו חייבת להישאר ירוקה ומטרתה למנוע יצירת מקור אמת מתחרה.

## QA קיים

```bash
node qa.mjs
```

לפני שינוי בדרישות: מעדכנים קודם את `SOURCE_OF_TRUTH.md`, ורק לאחר מכן את המימוש והבדיקות.
